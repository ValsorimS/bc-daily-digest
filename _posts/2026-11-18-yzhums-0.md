Verdikt: ANO – Zásadní architektonické oznámení Microsoftu s přímým dopadem na integrační vrstvu a nutnost refaktoringu OData endpointů před BC v30.0.

<!--více-->

- Microsoft od verze 2027 release wave 1 (v30.0) kompletně ruší možnost publikovat standardní Microsoft UI Pages jako OData webové služby (zákaz endpointů z UI vrstvy).
- Technická nutnost migrace integrací na dedikované `PageType = API` a API queries, které eliminují UI overhead (triggery, formátování) a přinášejí vyšší propustnost a stabilitu OData v4.
- Vyžadován audit stávajících integrací a záznamů v `Tenant Web Service` (Page data source) a jejich náhrada za moderní API endpoints nebo custom AL API stránky s pevnou entitní strukturou.
