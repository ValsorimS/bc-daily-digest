*   GA dostupnost funkce "rolling updates" pro Azure Functions hostované na Flex Consumption plánu.
*   Flex Consumption je hybridní hostingový model pro Azure Functions, kombinující serverless (pay-per-execution) fakturaci s rozšířenou kontrolou nad základní infrastrukturou a správou resource group.
*   Rolling updates umožňují bezvýpadkové nasazení nových verzí Azure Functions, čímž minimalizují dopad na runtime a zajišťují kontinuitu služeb během aktualizačních cyklů.
